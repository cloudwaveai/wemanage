# We-Manage 组织模块验收说明

- 版本：组织模块第一版
- 验证日期：2026 年 11 月 3 日，北京时间
- 访问入口：[We-Manage · 组织](https://ai.cloudwaveai.cn/wemanager/#organization)
- 验证环境：阿里云独立 We-Manage，使用已有飞书登录会话
- 验证方式：生产页面只读操作、隔离测试库自动测试
- 状态：功能已部署并完成以下技术验证；业务负责人验收意见待填写。

## 一、交付范围

1. 从现有飞书通讯录同步镜像读取部门层级及在职成员，显示最近一次成功同步时间。
2. 按全部可见成员、单个部门及其下属部门查看成员和用量。无调用记录的在职成员仍在列表中，可以进入人员页面。
3. 查看调用次数、输入和输出 Token、模型分布、错误调用，以及有单价时的分币种费用估算。
4. 按今天、昨天、近 7 天、近 30 天、指定月份或指定日期查看趋势；点击日期可查看 24 小时分布，并可展开完整数据表。
5. 排除私密人员及隐藏项目的调用；部门汇总按成员去重。

## 二、数据来源与口径

| 内容 | 口径 |
|---|---|
| 组织结构 | 网关已有的飞书通讯录同步镜像，按飞书应用的通讯录可见范围读取。现有同步任务每小时运行；页面显示最近一次成功同步时间，不宣称实时或全租户完整。 |
| 成员 | 飞书同步镜像中处于在职状态、非服务账号且未设为私密的成员。林伊默及其他私密成员不展示，也不计入组织汇总。 |
| 部门汇总 | 包含下属部门；成员属于同一部门树中的多个部门时，父部门汇总只计一次。成员属于不同部门时会分别出现在这些部门，直接相加可能重复。 |
| 历史部门 | 按最近同步的部门关系归集历史调用。当前没有部门任职历史，不能反映人员当时的历史部门。 |
| 组织总计 | 全部可见在职飞书成员的调用按人员去重；服务账号、停用人员等的可见调用单独说明，不计入该总计。 |
| 时间 | 北京时间；页面的结束时间为不包含的上界。当前月份截至查询时刻。 |
| Token | 输入与输出之和；缓存属于输入，推理属于输出，不重复计入总量。数据来自已有请求记录，不代表工作成果。 |
| 费用 | 根据调用时有效且已配置的单价估算，币种分开；未配置单价不按零元处理。该值不是实际账单。 |
| 数据覆盖 | 未接入网关或未记录的工作不会进入用量统计；当前部门关系及飞书应用可见范围可能不完整。 |

## 五、已知限制与后续事项

- 飞书通讯录当前仅通过既有同步镜像读取，不新增实时同步按钮，也不改动网关同步逻辑。
- 组织可见范围由现有飞书应用授权决定，当前结果不代表飞书全租户目录。
- 成员关系没有历史快照，不能据此追溯人员变动前的部门用量。
- 从组织成员列表进入个人页后，个人页使用自己的默认日期筛选；部门页的月份或日期暂不自动带入。
- 实际数据中暂无多部门成员或已配置价格的完整样本，相关边界需要具备样本后继续验收。
- 本阶段完成组织展示与用量下钻；尚未增加人员能力评分、项目进度百分比或组织绩效判断。
