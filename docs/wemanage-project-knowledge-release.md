# 项目知识深度整理上线记录

2026-11-05。入口：https://ai.cloudwaveai.cn/wemanager/#projects

## 已实现

- 从项目相关人员的完整日报分批提取事实，校验来源、日期及逐字引文，再合成跨日知识、问题状态和方法候选。
- 知识与进展摘要分别保存；展示来源、证据缺口和历史版本变化。同输入、规则及模型可复用结果。
- 方法以步骤与条件分支展示；缺失其他分支时明确停止并人工核查。
- 可保存为待审核组织资产，保留旧版本与全部来源依赖。来源转为私密或项目隐藏后，派生资产同样受限。
- 不删除正式数据，不修改网关代码，不自动发布模型产物。

We-PPT，2026-10-29 至 2026-11-05：7 份来源、13 条事实、3 个知识主题、3 项未闭环问题、1 个方法候选。

## 验证与限制

完整 We-Manage 模块测试通过，包含两阶段生成、引文校验、无损分批、结果复用、历史隔离、派生权限及归档幂等。阿里云服务健康检查通过。已在真实 Chrome 页面展开引文和条件流程，并将 We-PPT 结果保存为项目手册 v2 草稿；旧版本保留。

当前深度整理读取完整日报，并非全部原始请求日志。日报未记录的细节需要沿日志核查入口继续分析。引文匹配不等于语义正确，事实状态和方法仍需人工审核。

单次最多 31 天、来源 3.5 MB；合成账本最多 300 KB。超限明确失败，不截断材料。
