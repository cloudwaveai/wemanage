# 员工使用指南

第一次打开门户，"我的 Key"页最上面有一张"开始使用"清单，按顺序列出要做的几步和每步怎么做：管理员分配 AI 账号 → 安装 Codex（`npm install -g @openai/codex`，用 `codex --version` 检查）→ 生成 Key → 运行安装命令 → 在 Codex 里发一条消息检查。每步做完会自动打勾：Codex 有请求成功经过网关，最后两步就算完成，并显示是哪个客户端、什么版本；命令行版本比网关适配的版本旧时，会提示升级命令。清单可以收起，之后随时从右上角"使用指引"打开。

## 一、拿到你的 Key

1. 在飞书「工作台」里打开「AI 网关」（在飞书里打开会自动登录）；或者在浏览器打开公司发的网关地址（形如 `https://ai.example.com/`），用**飞书扫码登录**。
2. 进入"我的 Key"，点击生成。**Key 只完整显示这一次，请立即复制保存**。之后页面只显示打码版本；忘了可以自己重置（旧 Key 立即失效）。

## 二、配置 Codex（推荐）

### 一条命令配好（最简单）

1. 在「我的 Key」生成 Key 后，弹窗里直接给出安装命令（可以先选模型）。已经有 Key、要在另一台电脑上配置时，不用重置：在「我的 Key」页展开"已有 Key，在另一台电脑上配置"，粘贴 Key 就能拿到命令。
2. 复制命令：macOS / Linux 打开「终端」粘贴回车；Windows 打开 PowerShell 粘贴回车。
3. 看到"完成"后重新打开 Codex 即可。

这条命令会：
- 先备份原来的 `~/.codex/config.toml`（备份名带时间），只替换模型和网关这两部分，其它设置（MCP、项目信任等）都保留；
- ChatGPT 账号同时打开生图和联网搜索（真正的联网搜索，由 OpenAI 那边搜，不是让 Codex 在终端里 curl），走 WebSocket，和官方客户端一致；
- 终端里设了代理（`HTTPS_PROXY` 等）时，把网关域名加进直连名单（`NO_PROXY`），避免每次请求多绕几秒；
- 命令里不含 Key 本身，只有一个 10 分钟内有效、只能用一次的安装码，贴到哪里都不会泄露 Key。

### 切回官方登录

不用公司网关了、想换回自己的 ChatGPT 账号时，在「我的 Key」页展开"切回官方登录"，复制命令运行（macOS / Linux：`curl -fsSL https://ai.cloudwaveai.cn/restore | sh`；Windows：`irm https://ai.cloudwaveai.cn/restore.ps1 | iex`）。它只去掉网关写进去的那几行，其它设置不动，改之前先备份。

**用 CC Switch 的人注意**：上面的一条命令安装是直接改 `config.toml` 的，CC Switch 不知道。之后在 CC Switch 里切换时，它会把这份网关配置存进它当时认为在用的供应商（通常是「OpenAI Official」），于是"切回官方"切回来的还是网关。遇到这种情况运行上面的命令即可，它会把 CC Switch 里存进去的网关配置一并清掉（要先退出 CC Switch）。

### 用 CC Switch 导入（经常切换服务商的人）

1. 装好 [CC Switch](https://github.com/farion1231/cc-switch/releases/latest)。
2. 在生成 Key 的弹窗里展开"其他方式"，点「一键导入 CC Switch」。
3. CC Switch 会弹窗确认，点「导入」后 Codex 立即切到公司网关。

Key 只写进你电脑上的 CC Switch。CC Switch 导入的配置没有生图和联网搜索；要用的话，把同一处"手动配置"里的那段配置粘到 CC Switch 里这个供应商的 config.toml。

### 手动配置

在生成 Key 的弹窗（或"已有 Key，在另一台电脑上配置"）里展开"其他方式 → 手动配置"，复制那段配置——Key 已经填进去了。写入 `~/.codex/config.toml`（Windows 是 `%USERPROFILE%\.codex\config.toml`），原来的 `model_provider`、`model` 两行删掉：

```toml
model_provider = "aiseat"
model = "gpt-6-luna"   # 以弹窗里选的为准

[model_providers.aiseat]
name = "AI 订阅网关"
base_url = "https://ai.example.com/v1"
wire_api = "responses"
requires_openai_auth = false
experimental_bearer_token = "sk-emp-你的key"
supports_websockets = true
```

Key 直接写在文件里（`experimental_bearer_token`），不用再设环境变量，Codex 桌面版也能读到；这个文件别发给别人。`supports_websockets = true` 让 Codex 用 WebSocket 连网关，和官方 Codex 连 OpenAI 的方式一致；公司临时关闭 WebSocket、或你的账号不是 ChatGPT 时，页面上会写成 `false`。

**如果你电脑上开着代理 / 梯子**：Codex 会读取终端里的 `HTTPS_PROXY` 环境变量，请求会绕道代理——每次连接多花好几秒，还可能因为代理节点切换被风控当成"多个网络同时使用"。请把网关域名排除在代理之外（两种都做最稳）：

```bash
# 写进 ~/.zshrc 或 ~/.bashrc
export NO_PROXY="$NO_PROXY,.cloudwaveai.cn"
export no_proxy="$no_proxy,.cloudwaveai.cn"
```

并在代理软件的规则里把 `cloudwaveai.cn` 设为直连（DIRECT）。

之后照常使用 `codex` 即可。请求会经公司网关转发到你的专属账号。

## 三、其它客户端（OpenCode、Command Code 等）

**默认只允许官方 Codex 客户端**。第三方工具发来的请求会被网关拦截，返回 `client_not_allowed`，同时你会收到一条飞书提醒。

原因：第三方客户端的请求特征和官方客户端不同，容易让账号被 OpenAI 判定异常；另外，"只认 Codex"也让 Key 被拿去别的工具里转卖变得更难。

如果工作上确实需要，请联系管理员给你的账号打开"第三方客户端"。打开后，生成 Key 的弹窗里"其他方式"会给出现成配置（Key 和模型已经填好）：

- **OpenCode**：写入 `~/.config/opencode/opencode.json`（用 `@ai-sdk/openai`，走 Responses 接口）。
- **Command Code**：写入 `~/.commandcode/providers.json`（`api` 为 `openai-responses`），再把 `export AISEAT_API_KEY="你的 Key"` 加到 `~/.zshrc`，新开终端后在 Command Code 里用 `/model` 选"公司 AI 网关"的模型。
- 其他支持 OpenAI Responses 接口的工具：Base URL 填 `https://ai.cloudwaveai.cn/v1`，API Key 填你的 Key。

**多个账号**：管理员可能给你分配了不止一个 AI 账号（"我的用量"里能看到每个账号的额度）。不用做任何设置：同一段对话固定用一个账号，一个账号额度用完时网关会自动换到另一个。

**可用模型**：管理员可能限定了你账号能用的模型。用了不开放的模型时，Codex 里会提示可以用哪些，输入 /model 换一个就行。

## 四、查看用量和额度

- **额度提醒**（默认开）：5 小时或每周额度用到 80% 时，以及用完时，各收到一条飞书消息，写着什么时候恢复（用完时的那条会顺带说还有几张重置卡）。每个额度窗口各提醒一次，只发给你自己；不想收可以在"我的用量"的额度卡片里关掉。
- **重置卡**：OpenAI 会不定期给 ChatGPT 账号发重置卡（例如"Full reset (Weekly + 5 hr)"，有效期约一个月）。用一张，5 小时和每周额度立即清零、重新开始。在"我的用量"的"重置卡"一栏里，每张卡单独列出，写明哪天到期、还剩几天；为降低账号风险，公司规定重置卡原则上不用：只有 5 小时或每周额度已经用完、确有急需时才能使用，点"使用一张"并确认即可，会先用最早到期的那张。
- **选模型**：日常任务用 luna，复杂任务用 sol；Astra 消耗额度最快，只在确有需要时在 Codex 里临时切换，不要设成默认模型。只要不大量使用 Astra，20X 账号日常基本用不完。

- **我的用量**：今天 / 最近 7 天 / 30 天的请求数和 token 数，可按模型、按客户端查看。
- **账号额度**：你的账号 5 小时窗口和每周窗口的使用比例、恢复时间，以及账号当前状态。
- **使用日志**：你每次调用的时间、模型、状态、Token 和耗时（和常见 API 平台的调用日志一样，不显示对话内容）。失败的请求会在状态旁写明原因，比如"新电脑待确认""账号额度用完"。请求结束后一两秒就会记下来，页面每 10 秒自动刷新。
- **我的周报**：每周日下午，系统根据你本周在 Codex 里做的事自动编写本周周报，通过飞书发给你，省去你编写周报的麻烦：复制后稍作修改就能提交（"我的周报"里每份都有"复制周报"按钮）。只发给你本人，部门负责人和其他人都看不到。不需要可以在"我的周报"里关掉，关掉后不再生成也不推送。

## 五、常见问题

网关拦下请求时，Codex 里会直接显示一句中文说明，告诉你原因和下一步怎么做，不会反复重试。同样的原因也会出现在"使用日志"里那条请求的状态旁边。常见的几种：

| Codex 里看到 | 怎么办 |
|---|---|
| 这台新电脑还没确认是你本人 | 点消息里的链接，或到"我的设备"点"是我"，然后重新发一次 |
| 这个账号的额度用完了，预计 xx:xx 恢复 | 等到那个时间再用。Codex 显示的是英文 "You've hit your usage limit. Try again at …"，意思一样 |
| 你的 AI 账号登录已失效 | 管理员已收到通知，重新登录后就能继续用 |
| 你还没有分配 AI 账号 | 管理员已收到通知，分配好后飞书会告诉你 |
| 这个 Key 已经重置过，旧 Key 不能再用了 | Codex 里还是重置前的旧 Key。到"我的 Key"重置一次，用弹窗里的安装命令重新配置 |
| Key 无效 | 到"我的 Key"生成新 Key，按弹窗里的安装命令配置 |
| 这台电脑已被停用 | 你点过"不是我"，或管理员停用了这台电脑。需要恢复请找管理员 |
| 你的 Key 已被暂停 | 见下一节"什么情况会被冻结"，联系管理员 |
| 只能在公司网络里使用 | 公司开启了"只允许在公司网络内使用"。需要在外办公请找管理员开通远程使用 |
| 触发了公司的 AI 使用规则 | 这条消息触发了内容审核规则（例如要求写恶意软件、盗号工具、免杀程序），这类请求会让 OpenAI 直接封号。如果是误判，把原始需求发给管理员核实 |

其它：

- **同时请求太多**：默认一个账号最多同时处理 4 个请求，Codex 会自动重试。
- **不要在对话里粘贴密码、密钥、私钥**：系统会尽力脱敏，但不保证覆盖所有情况，而且这些内容本就不该发给模型。
- **换电脑**：重新导入配置即可，Key 不用换。新电脑第一次使用时会收到"新设备"提醒，确认即可。

## 六、设备确认与账号安全

你的 Key 只属于你一个人。为了防止 Key 被分享或转卖（外人用你的账号会让账号被 OpenAI 降智甚至封禁，公司也要替外人付费），网关会记录 Key 在哪些**设备**和**网络**上使用。

**新设备要确认。** 你第一台用 Key 的设备会自动信任，不用确认。之后 Key 第一次在另一台设备上使用时，你会收到飞书消息。点消息里的链接打开"我的设备"：

- 是你本人的设备：点 **是我**。
- 不是你：点 **不是我**。这台设备会被拉黑，你的 Key 会**立即作废**，请马上到"我的 Key"重新生成，并通知管理员。

没确认的设备可以先用 24 小时（管理员可调整），超时后会暂停，确认后恢复。

**什么情况会被冻结。** 下面两种情况几乎只会在 Key 被多人同时使用时出现，系统会自动冻结你的 Key：

1. 一台**没确认**的设备，和你的另一台设备在**不同网络**上几乎同时使用（新设备有 30 分钟宽限）；
2. 短时间内（默认 10 分钟）在 **3 个以上**不同网络同时使用。

冻结后你无法使用 Key，也不能自己重新生成，**只能由管理员核实后解冻**。如果你认为是误判，直接联系管理员说明情况即可。

**内容审核。** 每个请求发给 OpenAI 之前，网关会用规则检查你最新的一条消息，只看这一条，不看历史对话和工具输出。命中"写勒索软件、盗号、免杀、发起 DDoS"这类网络滥用规则时，管理员会收到提醒；如果公司设成了拦截模式，这条请求会被直接拒绝。正常的安全开发工作（修漏洞、写单元测试、做加固）不在规则范围内。

**避免误判的建议：**

- 及时确认自己的新设备。
- 不要用会自动切换节点的代理 / VPN 访问网关，把网关域名设为**直连**。节点频繁切换会被看成"好几个地方同时在用"。
- 办公室和家里各一台电脑没问题，只要都确认过，同时用也不会冻结。
