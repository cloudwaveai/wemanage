# 员工使用指南

## 一、拿到你的 Key

1. 打开公司发的网关地址（形如 `https://ai.example.com/`），用**飞书扫码登录**。
2. 首次登录会看到一条使用说明：你在这里的请求和回复会被公司记录，用于用量管理和工作分析，原文保留 180 天。阅读后点击"我已知晓"。
3. 进入"我的 Key"，点击生成。**Key 只完整显示这一次，请立即复制保存**。之后页面只显示打码版本；忘了可以自己重置（旧 Key 立即失效）。

## 二、配置 Codex（推荐）

在"一键配置"里复制 Codex 配置片段，写入 `~/.codex/config.toml`：

```toml
model_provider = "company"
model = "gpt-5.1-codex"

[model_providers.company]
name = "Company Gateway"
base_url = "https://ai.example.com/v1"
wire_api = "responses"
requires_openai_auth = false
```

然后设置环境变量 `OPENAI_API_KEY`（或 Codex 读取的对应变量）为你的 `sk-emp-...` Key：

```bash
export OPENAI_API_KEY="sk-emp-你的key"
```

之后照常使用 `codex` 即可。请求会经公司网关转发到你的专属账号。

## 三、其它客户端（Cursor / Cherry Studio 等）

同样在"一键配置"里有对应说明。要点：

- Base URL 填 `https://ai.example.com/v1`
- API Key 填你的 `sk-emp-...`
- 模型选网关返回的模型名

> ⚠️ 第三方客户端的请求特征和官方客户端不同，账号风险相对更高。**能用 Codex 就优先用 Codex。**

## 四、查看用量和额度

- **我的用量**：今天 / 最近 7 天 / 30 天的请求数和 token 数，可按模型、按客户端查看。
- **账号额度**：你的账号 5 小时窗口和每周窗口的使用比例、恢复时间，以及账号当前状态。
- **我的日报**：每天早上系统会根据你前一天的使用，自动生成一份工作小结推送到飞书。

## 五、常见问题

- **返回"账号需要重新登录"**：你的上游账号 token 失效了，管理员已收到通知，稍等即可。
- **返回 429 / 限额**：账号命中了 5 小时或每周额度上限，页面会显示恢复时间；或同时并发太多（默认最多 4 个），稍后重试。
- **不要在对话里粘贴密码、密钥、私钥**：系统会尽力脱敏，但不保证覆盖所有情况，而且这些内容本就不该发给模型。
- **换电脑**：重新复制配置片段即可，Key 不用换。
