# We-Manage 管理与费用更新验收（2026-11-05）

入口：https://ai.cloudwaveai.cn/wemanager/#expenses

## 已实现并部署

- 订阅来源：只读网关账号、套餐、订阅状态、续费/到期时间、核查时间及可见人员。账号邮箱、认证文件名、密钥不返回前端。涉及私密人员的订阅不展示。
- 从订阅账号预填实付登记表；金额不预填、不按套餐伪造实际付款。未核查、核查失败与未登记金额分别展示。
- 真实费用：按月、类型、币种登记，近六个月对比、人员关联、版本记录、可恢复撤回；不与 Token 估算相加。
- 人员工作回放：日期×24 小时热力图，项目筛选、时段用量、当天线索和完整日报。日报不归因到小时，用量不代表工时或绩效。
- 项目分析：演变时间线、事实与证据联动，保留完整分析。
- 项目维护：负责人、状态、启动与验收日期、回款节点、版本记录。普通成员只能维护自己的项目。
- 知识审核：分配真实成员审核草稿；待审核、重要但难、需补充、通过。发布检查最新版本，来源变私密后隐藏。

## 本次费用范围

用户确认先接现有订阅，API 渠道后续配置。当前核查到 3 个 Pro、1 个 Plus；网关 API 渠道为 0。仅凭 pro 套餐字段不能确认具体价格档位，也不能据此生成实付记录。

DeepSeek 与火山显示未连接，本版没有调用其费用接口或部署账单同步器：

- DeepSeek 的 `/user/balance` 提供余额，余额差不能直接当月消费：https://api-docs.deepseek.com/api/get-user-balance/
- 火山可使用账单接口，需另行配置对应账号的账单读取权限：https://docs.volcengine.com/docs/billing-center/list-bill-detail-page-query-bill-details?lang=zh

网关代码和网关入口未修改。正式库无清理、无伪造费用记录。

## 人工验收路径

1. 真实费用：查看订阅清单；点账号实付登记，检查套餐、账号和成员预填，金额应为空。
2. 人员画像：选真实成员，点击热力图时段，检查用量和当日完整日报。
3. 项目分析：点击演变节点并展开证据；在项目管理维护真实负责人及节点。
4. 知识审核：分配真实草稿后由审核人登录，查看全文并提交判断；其他成员不得读其任务或原始日志。

当前没有替用户提交虚构费用、项目日期或真实审核任务。
