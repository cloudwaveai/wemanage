# 每日自动整理与历史批次

本轮补齐上一版未开启的每日定时任务，仅修改 We-Manage。

- 默认北京时间每天 09:00 检查现有已完成的日报/周报提取线索。管理员可在“知识审核 → 每日自动整理”修改时间或暂停。
- 每个管理员每天持久化一次执行记录。服务重启、多次检查不会再次启动当天任务。停机后恢复时，只补做当天到点的检查，不堆积过往日期。
- 检测到近 30 分钟仍在生成的知识提取任务，会等待其完成；旧的中断任务不会永久阻塞定时检查。
- 复用原有材料和模型指纹：没有变化时不再调用模型。失败状态可见，不无限自动重试，可从页面手动重试。
- 项目归并、资产发布继续由人工确认，定时器不作审核决定。
- “整理批次”可返回历史结果与各批次审核状态。历史结果仍动态检查全部来源可见性；私密或隐藏的来源不会通过历史入口重新公开。
- 暂停阻止尚未开始的任务，不中断已经发送给模型的工作。

验证：独立数据库测试覆盖北京时间到点、等待输入、每日重复检查、结果复用、暂停、权限隔离与历史读取；本地浏览器验证修改时间、暂停与历史切换，以及手机布局。

本机工作目录部分旧文件被 Go 读为空，未修改这些无关文件；使用 Git 源码快照叠加本次改动，在 /tmp 独立目录完成测试与构建。
