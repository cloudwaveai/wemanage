# 工作数据与 API 渠道

网关只记录经过它的请求。直接调用其他服务或绕开网关的工作，不在当前统计中。没有网关记录不代表没有工作；Token 数和请求数不能作为个人表现的评分。

## 记录字段

在「对话记录」打开单条记录后，可展开「读取记录字段」。页面显示保存的元数据与重建片段。字段含义：

| 字段 | 含义 |
| --- | --- |
| `started_at` | 请求开始时间。数据库保存带时区的时间；页面按浏览器时区显示到秒。 |
| `employee_id` | 使用密钥的员工或服务账号。服务账号不代表一个自然人。 |
| `account_id`、`api_key_id` | 路由使用的订阅账号和网关密钥；不存在时为 null。 |
| `session_id` | 网关识别的会话。 |
| `client_kind`、`endpoint`、`stream` | 客户端类别、接口和是否请求流式输出。 |
| `model_requested`、`model_responded` | 请求和响应中的模型名称。 |
| `tokens.input`、`cached`、`output`、`reasoning` | 请求上报的 Token 数；缓存属于输入，推理属于输出。 |
| `status_code`、`duration_ms`、`queued_ms` | 状态、总耗时与排队时间。 |
| `project_id`、`project_manual` | 项目归属及是否人工指定。缺失表示尚未归属。 |
| `transcript` | 按保存的内容片段重建的请求和响应；`purged` 表示正文已清理。 |

片段在保存前会按规则脱敏，不是未经处理的原始网络报文。未成功采集、未经过网关或已清理的内容不能从记录中恢复。历史精确时间只能从现存时间戳或仍保有原始时间的来源恢复，不从日期推算。

生产环境原有配置在保留期届满后清理对话正文和派生总结，核实值为 180 天。新版本默认关闭正文自动清理；只有上线并生效后才改变线上行为。管理员若显式启用清理，超过设置天数的正文和总结会永久删除。请求元数据保留。上线前需核对数据库容量与备份恢复。

导入的历史记录可能有 Token 为 0 的情况；这些记录的请求条数不等同于实际模型调用次数。

## 工作、项目和复盘

在「项目与用量」创建客户项目或基础建设项目。服务账号的新密钥可以绑定项目；单条历史记录可在详情中补充或修改项目归属。修改保留原记录和历史归属。没有明确归属的记录显示为「未分配」。

项目时间线记录人员、发生时间、工作过程和成果线索，手工保存，不猜测缺失的历史时间。月度和季度复盘可选择上个月或上季度，查看同一范围内的用量后填写复盘；复盘是人工记录，不自动判断个人表现。林伊默的工作正文、项目事件和本人复盘不会向其他管理员展示，也不进入共享总结。

## 应用 API 渠道

管理员在「API 渠道」添加 OpenAI 或 Anthropic 协议的 HTTPS 公网上游，填写提供商的基础地址（通常以 `/v1` 结尾）和 API 密钥。上游密钥加密保存，可以更换或停用。随后在「员工」创建服务账号，在「管理密钥」中生成绑定渠道和项目的应用密钥。明文应用密钥只展示一次。

- OpenAI 渠道支持 `/v1/chat/completions`、`/v1/responses` 和 `/v1/models`。
- Anthropic 渠道支持 `/v1/messages`、`/v1/messages/count_tokens` 和 `/v1/models`。
- 两种渠道按原协议转发，不做跨协议转换；WebSocket、图片和搜索不通过这些渠道转发。
- 为防止渠道访问内部服务，只允许 HTTPS，解析到私网或本机的地址会被拒绝；不自动跟随重定向。
- 停用渠道会拒绝后续调用。撤销应用密钥受鉴权缓存影响，数据库断连时最长可能延迟 10 分钟。

调用数据包含使用量和脱敏后的工作记录。渠道费用由上游收取，实际可用模型、价格、额度及账单以上游为准。上线前须用获授权的真实渠道分别验证，不应把本地模拟成功当作供应商接入成功。

## 费用估算

在渠道的「模型价格」中为模型填写币种、输入、缓存和输出每百万 Token 的单价及生效时间。系统按请求时间选择对应价格；缓存 Token 不再按普通输入价重复计算。统计按人员、项目、模型、上游和币种分组。币种不会混加。

价格是管理员输入的估算依据，不是自动获取的账单。没有价格、使用订阅账号或历史导入的记录显示「未定价」，不会假设为免费。实际账单、阶梯价格、其他收费项和供应商口径差异仍需人工核对。
