# We-Manage 界面与项目工作台调整

## 本轮范围

只修改 We-Manage。以现有网关的白色侧栏、浅灰背景、系统字体和靛蓝操作控件统一视觉。未修改网关代码和原始日志。

导航由所有页面共享一份组件：组织、人员、项目、知识库、费用与用量、总结。组织概览、负责人维护、专家审核等作为当前栏目下的入口；旧链接继续有效。数据入口收在侧栏底部。

## 项目流程

日志提取名称 → 待归类 → 归并已有项目 / 确认为项目 / 隐藏 → 负责人维护节点 → 查看项目记录与知识。

- 已确认项目表显示负责人、状态、启动/验收日期、下一回款节点。
- 待归类表显示来源人员、记录范围、线索数量，不把模型提取名自动认定为独立项目。
- 同名格式优先推荐归并，涉及业务意义的合并仍由人核对。没有自动把所有带 PPT 的名称强行合并。
- 点击维护直接打开对应项目并带入现有值；保存返回项目详情。项目详情显示全部回款节点及工作线索。
- 已隐藏记录可恢复，原始日志和线索不删除。

## 验证

- 新增导航测试覆盖全部路由只有一个当前栏目、成员导航无管理数据入口。
- 项目工作台测试覆盖正式项目与提取名分开，以及维护入口带入已有负责人、日期。
- 原组织成员去重测试通过；5 项前端测试通过。
- 变更 JavaScript 语法检查、差异格式检查及 Linux 发布构建通过。

- 项目归类请求测试确认使用现有 PUT 接口及 CSRF，不会因为请求方法不匹配导致按钮失效。
- 项目归并、隐藏、隐私隔离和管理归属的后端针对测试通过（1.535s）。
- 已实际打开网关作视觉对照，检查新项目工作台、待归类 28 条数据、六位真实成员页面及统一侧栏的截图。
- 新增项目表单字段通过渲染测试；生产中没有提交虚构项目、负责人、日期、费用或实际归并。用户同时操作浏览器，未完成所有表单的现场点击验收；移动端仅完成样式适配，未做设备实测。
- 最终发布为 ui2-20261105。服务健康检查通过，线上项目模块和样式与本地一致。
