# 组织资产第一版发布记录

2026-11-04。入口：https://ai.cloudwaveai.cn/wemanager/#assets

## 可用功能

- 从已有项目、问题和 Skill 分析整理草稿，不重复调用模型；已有 Skill 正文完整导入。同一来源和类型只创建一次，不覆盖人工编辑。
- 项目手册以来源条目组织；管理员补全目标、职责、文档、约束。项目全貌仍通过工作时间线查看。
- 待决策事项保留问题、选项、依据和最终决定，支持标记已处理，不自动替负责人决策。
- Skill 正文按章节绘制流程预览；分支条件以章节文字表达，尚无可执行的分支引擎。
- 人工发布项目手册和 Skill 后，有效成员可通过飞书登录读取。草稿、待决策事项、历史版本和原始日报仅管理员可访问。
- 编辑、发布、撤回均新增版本；过期版本编辑返回冲突。撤回后成员立即不可见。
- 来源被排除、项目被隐藏或来源人员变为私密，派生资产同步隐藏。林伊默来源持续排除。不删除正式记录。

## 验证

新增集成测试验证未登录、成员越权、CSRF、草稿隔离、发布、撤回、版本冲突、私密来源变化、历史保留、重复整理去重。

We-Manage 和日志分析模块复验通过。全仓首轮测试有一例调度锁暂不可用，针对所属模块重跑通过；不将首轮描述为全通过。

## 使用方式

管理员打开“组织资产”，点击“整理已有分析”；核对草稿，补充缺失条件后保存为“已发布”。普通成员登录后只进入已发布资产列表。发布是人工审核动作，系统不会自动把草稿公开。

## 后续边界

当前以已有提取结果为起点，不代表全量日志已分析。项目手册条目不会自动合成为完整项目手册；跨项目知识同义归并、项目级成员授权、岗位/Exam、可执行 Skill 和机器人主动通知尚未实现。

线上实测：管理员已点击“整理已有分析”，真实草稿已持久保存；已展开实际写作方法 Skill 检查完整步骤、验证与边界。没有自动发布任何草稿。
