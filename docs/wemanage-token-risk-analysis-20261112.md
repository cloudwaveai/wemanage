# Token 用量与风险核查

新增入口在“费用与用量”下：`#token-analysis`、`#risk-analysis`。仅有效超级管理员可访问；普通成员和未登录请求均拒绝。只读查询，不调用模型、不自动处理告警，不修改网关拦截规则或日志。

## Token 分析

- 按人员和北京时间日期筛选，最多31天，支持昨天、今天、近7天。
- 展示总Token、非缓存输入、缓存输入、输出、推理、请求及异常。总量=输入+输出；缓存与推理是子集，不重复相加，也不等同实际费用。
- 对照上一个同跨度时间段；包含今天时，比较同样已经过去的时长，明确展示两段起止时间。
- 按日、小时、请求模型、人员、会话下钻，显示缓存率、最高单次输入、异常请求已记录Token和会话集中度。HTTP 200但error_type非空也计为异常。
- 会话提取文本分页读取，每页50条，继续加载可读取全部可见条目。保留原文、不进一步截短。网关采集本身每条最多8000字；user角色可能是代理交接或历史上下文，不自动认定为本人输入。
- 指标仅反映可见网关请求，不自动推断任务根因、员工绩效或实际账单。

## 风险核查

- 每页100条，继续加载保留完整结果；区分已处理、内容仅提醒/已放行和已拦截。
- 展示命中时保存的片段、规则和严重度。对av-evasion片段中“避免杀…”与“免杀”的词组碰撞显示“疑似误报”，不自动认定已经审核。
- 可跳到对应人员、日期的Token及会话证据。告警没有request_id，日期链接不是精确请求关联；片段不是完整请求。
- 告警有去重，记录条数不是命中请求次数。私密人员完全排除；因为风险事件不能精确关联请求，有隐藏项目历史活动的人员暂不展示风险记录，避免泄露无法确定项目范围的摘录。

## 验证

- 后端日期/部分日对照、误报提示单测通过；Go vet与Linux构建通过。
- 独立临时PostgreSQL数据库验证管理员/成员/匿名权限、私密状态变化、隐藏项目、模型与总量对账、HTTP200错误统计、100+2条风险分页、50+10条原文分页。
- 前端12项测试通过；JS DOM与真实合成接口联测覆盖日期/人员筛选、Token数值、原文/风险分页、HTML转义及错误反馈。
- 浏览器控制宿主不可用，未完成真实浏览器视觉、点击及窄屏实测。DOM测试不替代这项验收。
- 测试数据库与生产隔离，未在生产创建测试员工或调用模型。
